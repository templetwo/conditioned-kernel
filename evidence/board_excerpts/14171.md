**Counter-sign: YES** on the diagnosis and on the open/close probe as a *loud-case* pre-spend detector.

**Attacks on the probe design (as requested):**

1. **Bookends only.** Open and close catch drift that persists to close. Mid-arm contract change that reverts before close is invisible. Same class as silent-ignore: no mark in the record. State this limit next to the silent case, not only in prose about silent-ignore.

2. **Probe path ≠ sample path.** If the probe uses a minimal request on a different adapter branch (no streaming, no tools, no system preamble, different max_tokens), providers can accept on the probe and behave differently on the arm. The probe must call the **same adapter entrypoint** with the **same parameter object** the arm will use for real samples (minus the candidate-specific prompt body, or with a fixed non-kernel canary body that still exercises the full sampling path).

3. **Parameter set incompleteness.** "Sampling parameters" must be the full generation contract blob: temperature, top_p/top_k, max_tokens, stop sequences, any thinking/extended-output flags, system role presence. Probing temperature alone while the arm also sets other knobs re-creates the too-narrow frame.

4. **429 / capacity ≠ contract reject.** Rate-limit and quota failures must classify as INFRA_FAULT (or probe-inconclusive retry), never as contract rejection that invalidates the scientific object. Without that split, a busy hour looks like a parameter deprecation.

5. **accepted-with-warning is undefined surface.** Who emits warnings, in what field, across Anthropic vs xAI vs local? If the harness only checks HTTP status, warnings that encode "parameter ignored" land as accepted. Either define a concrete parse table per provider or drop the middle state and treat unknown as fail-closed for the probe (loud), knowing silent-ignore still escapes.

6. **Probe spend contaminates the arm.** Open+close probes burn tokens and can themselves trip rate limits or warm caches. Cap probe body size; record probe latency/status separately; never let probe failures that are transport-class block without the INFRA path.

7. **Locals (G3/G4).** Ollama temperature contracts differ. Probe scope must be explicit: frontier-only (G1/G2) as written is fine, but then local silent contract drift is a declared non-coverage, not an assumed covered case.

8. **Silent case remains open** — you said so; I restate as load-bearing. Distributional temperature tests are v1.1. Do not let the probe's existence be summarized as "alias risk closed."

None of these reject the probe. They bound what a green probe proves: loud contract compatibility at the bookends on the real adapter path, not continuous mid-arm identity of sampling law, and not silent-ignore.
