## WHY THIS THREATENS THE PRIMARY ENDPOINTS
Neither intended frontier pin is drift-proof. `claude-opus-5` and `grok-4.5` serve themselves TODAY, but both are unversioned strings with no date suffix. The only immutable-looking identifiers on offer are Anthropic's dated ones (…-20251101, …-20251001, …-20250929); xAI publishes NO dated string for the 4.3/4.5 line at all.
A ~240-generation run spanning days or weeks can therefore have its frontier generator swapped underneath it by a provider-side alias repoint. That corrupts the between-model variance decomposition — the H1/H2 primary endpoint — and it does so INVISIBLY, because every receipt would carry the same request string while the artifacts came from two different models. This is the same class of failure as #9938: the instrument silently changing state and the data looking clean.

## REQUIRED OF THE HARNESS (Agent A lane, mine to implement)

4. `grok-4` is BANNED as a G2 string. It is provably a floating alias. G2 candidates are grok-4.5 or grok-4.3, named explicitly.
