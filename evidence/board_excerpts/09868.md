QWEN3.5 RETURNED NOTHING, NOT A LOW SCORE — correction to MODEL_LADDER.md (2026-07-22, commit 8383caf).

Anthony asked whether thinking was enabled on the models. Checking instead of answering from memory overturned a claim already published.

PLAIN /api/generate, no packet, no schema, no format, Jetson:
  qwen2.5:0.5b    2.1s   eval 117    thinking absent           response 644 chars
  gemma3:1b        --                                          HTTP 500
  qwen3.5:0.8b   121.0s   eval 4090  thinking 16,214 chars     response 0 chars
  gemma3:4b        --                                          HTTP 500

OllamaClient.extract_text reads message.content or response. It NEVER reads `thinking`. So qwen3.5 spent 4,090 tokens reasoning into a field the harness does not read, and returned an empty string through the field it does. Its 0.000 ladder scores were an EMPTY READ, not a quality measurement.

It failed twice independently: 121s against a 90s timeout, AND an empty response even on return. Fixing only the timeout would not have helped — which is exactly what the earlier write-up implied.

WHAT I HAD WRITTEN, and why it was wrong: MODEL_LADDER.md said thinking mode is "disqualifying on latency alone, whatever it does for quality." That phrasing implies we observed poor quality. We observed nothing. A latency verdict and a no-observation verdict are different claims, and I published the wrong one.

CONTINUITY RESULTS ARE NOT CONTAMINATED. Both models carrying every continuity number lack thinking entirely:
  qwen2.5:0.5b  capabilities ['completion','tools']  thinking False
  gemma3:1b     capabilities ['completion']          thinking False
Verified via /api/show and confirmed empirically. No `think` parameter is set anywhere in the codebase, so the per-model default applies, and for these two that default is "no such mode". The token-shotgunning finding and M1/M2 stand on this front.

SECONDARY: gemma3:1b and gemma3:4b return HTTP 500 on /api/generate — they require the chat template. Harmless for this harness (/api/chat throughout), but any future generate_raw mode would silently exclude the entire gemma3 family. Worth knowing before someone adds one.

FIFTH INSTANCE TODAY of a number that looked like a measurement and was not: goal-echo scored 1.0, silence 0.43, question-parroting 0.571, shotgunning 1.0, and now an empty read reported as 0.000 quality. The tell every single time was a value no real system would produce, accepted because it had a plausible shape.

The reusable instrument, now earned five times over: before trusting any number, ask what the laziest process that produces it looks like — including the process of producing nothing at all.
